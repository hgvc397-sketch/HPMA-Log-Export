# 魔法覺醒資料匯出工具（新手使用教學）

幫《哈利波特：魔法覺醒》Android 玩家在本機備份自己的帳號資料、牌組、衣櫃外觀、聊天紀錄、創作圖檔，以及 **3D 角色與神奇動物模型**。

> **支援版本**：台港澳服、中國版（官服／管道服）、全球／國際服、日服與韓服  
> **系統需求**：Android 8.0 以上（一般手機、ROOT 手機、MuMu 等 Android 模擬器皆可使用，內建繁體中文／英文切換）

- **ROOT 手機／Android 模擬器**：在首頁勾選 **「ROOT 深度模式」**，即可直接離線讀取手機內的原版遊戲模型包，免開 Shizuku，關服後只要原版遊戲資料還在就能繼續提取。

## 2. 開始前必做：先回原版遊戲「點一圈」

遊戲只會把你**最近打開看過的內容**寫進手機快取與日誌。建議備份前先開原版遊戲做一次以下動作（約 3 分鐘）：

1. **牌組與戰鬥資料**：把你想保留的每套牌組，各帶去打一場練習賽或決鬥（會寫出迴響詞條、卡等、熟練度、護法、掃帚、卡牌造型）。
2. **衣櫃與造型**：進衣櫃換穿幾套想留的造型，並點開**魔杖、稱號、頭像框、迴響、巫師空間家具**分頁。
3. **宿舍與聊天**：打開一次**宿舍留言板**與**聊天室**（更新簽到天數、對話、大頭貼與決鬥段位）。
4. **巫師空間**：進一次自家空間，讓遊戲生成最新縮圖紀錄。

## 3. 新手 5 步驟完成備份

### 步驟 1：安裝本 App
1. 到本頁右側 **[Releases](../../releases)** 下載 APK 到手機。
2. 點開 APK 檔案；若系統提示「不允許安裝未知應用程式」，依畫面指示開啟「允許來自此來源的應用程式」後完成安裝。

### 步驟 2：準備讀取權限（二選一）

- **A. 一般手機（未 ROOT）— 使用 Shizuku**
  1. 打開本 App，如果不知道怎麼設定 Shizuku，直接點首頁最下方的 **「新手教學」**（內建繁中字幕操作動畫＋各品牌防殺背景教學）。
  2. 也可參考 [Shizuku 官方繁中設定手冊](https://shizuku.rikka.app/zh-hant/guide/setup/)，用手機內建的「無線偵錯」完成配對並啟動 Shizuku（Android 11 以上免接電腦）。
- **B. ROOT 手機／模擬器（如 MuMu 模擬器）**
  - 免裝 Shizuku！直接在首頁勾選 **「ROOT 深度模式」**，跳出超級使用者授權時點允許即可。

### 步驟 3：選擇遊戲版本並抓取資料
1. 在首頁「**1. 來源與抓取**」選單中，選擇你玩的版本（預設為台港澳服；右上角可切換 `EN`／`繁中`）。
2. 點 **「允許存取」**（授權 Shizuku）或 **「自動抓取」**。
3. 等待數秒完成本機解析，畫面會顯示已讀到的日誌數、角色數、外觀套數、牌組與快取筆數。
   > 回原版遊戲補看更多造型或牌組後，再回來按一次 **「自動抓取」**，App 會**自動合併並保留先前的紀錄**，不會覆蓋掉舊牌組與舊造型。

### 步驟 4：檢查資料並儲存備份檔
在首頁「**2. 預覽與資料備份**」中：
1. 點 **「預覽人物、牌組與收藏」**，確認角色資料、段位、牌組與藏品都有抓到。
2. 依需要按下存檔按鈕（預設全選，也可自行勾選要保留的分類）：
   - **儲存 JSON**：**完整個人備份**（內含個人識別、聊天紀錄與相片網址，請自己保存好，**不要直接公開上傳**）。
   - **儲存去個資分享版 JSON**：已自動遮蔽帳號、UID、聊天內容與私密網址，適合分享給朋友或社群。
   - **儲存作品／檔案 ZIP**：打包巫師空間縮圖、DIY 花藝／盤飾／帽子／蛋糕圖、大頭貼與自訂上傳表情等原始圖檔。

### 步驟 5：預覽並保存 3D 角色模型
在首頁「**3. 3D 角色與奇獸模型**」中：
1. 點 **「角色 3D 預覽」**：可旋轉、縮放、切換「臉部／全身」檢視你目前的造型與臉型妝容（支援全部 190 款臉型，包含原版 98 款精緻臉型捏骨、髮色染色、衣服染色與戴帽髮型規則）。
2. 點 **「儲存角色模型 ZIP」**：把 3D 模型原檔（`.mesh`、`.mb` 捏骨、`.astc` 貼圖與配方 `face_recipe.json`）完整打包成一份 ZIP 留存，之後隨時可在電腦轉成常見 3D 模型（OBJ＋PNG）長期保存。
3. 點 **「神奇動物 3D 預覽」**：可檢視 22 隻神奇動物（玻璃獸、拜月獸、變形兔等）的預設 3D 外觀。

## 4. 常見問題（FAQ）

### Q1：這個工具安全嗎？會上傳我的帳號資料嗎？
- **不會**。帳號日誌解析、快取解密與備份打包全部在你的手機本機完成，不會上傳個人帳號資料到任何第三方伺服器。
- 唯一會連網的動作只有一般手機在使用「角色 3D 預覽／儲存角色模型 ZIP」時，向遊戲官方 CDN 下載公開的 3D 模型與貼圖檔（不含個人資料）。

### Q2：手機重開機後按「自動抓取」失敗怎麼辦？
- Android 重開機後會自動關閉 Shizuku，請先重新開啟一次 Shizuku 服務，再回到本 App 按 **「自動抓取」** 即可。

### Q3：點「角色 3D 預覽」時失敗或卡住？
- 一般手機請確認手機有連上網路（Wi-Fi 較快），首次預覽需要下載該角色用到的模型檔，第二次之後會直接走本機快取秒開。
- 若你是 ROOT 手機或模擬器，請勾選首頁的 **「ROOT 深度模式」**，會直接從本機遊戲資料夾讀取。

### Q4：Android 11 以上可以不用 Shizuku 嗎？
- 可以用首頁最下方的 **「手動匯入日誌」**，先用電腦透過 USB 把遊戲資料夾的 `log.txt`、`log_old_*.txt` 複製到手機下載資料夾後再手動選取；但手動模式只能匯入文字日誌，無法自動打包 `Documents/` 作品圖檔。

### Q5：什麼東西沒辦法靠匯出工具保存？
- 僅存在官方伺服器、從未在手機上點開過的道具明細，以及即時寶石／金幣餘額不會出現在本機快取；建議搭配原版遊戲內的**截圖或錄影**一起留念。
